# 考研打卡 · 2028

个人备考用的安卓手机 PWA：每日保底任务、阶段计划、分科学习时长、章节进度、模考记录、周目标、统计与节点提醒。

## 使用

在线入口：https://xjb1337.github.io/kaoyan-checkin/

安卓 Chrome 打开后，可通过菜单「安装应用」或「添加到主屏幕」安装。详细操作见 [使用说明.md](使用说明.md)。

**数据只在当前浏览器本机，没有 GitHub 云同步。** 代码发布不上传学习记录。升级保留 `kaoyan2028_v1` 存储键；换机、清浏览器数据前须导出 JSON，并保存到手机外。

每天优先完成两项最低线：英语词汇 15–25 分钟，以及西综学习或复习至少 20 分钟（可包括章节题）。其余阶段任务是按周安排的参考，不要求每天全部完成。可参考英语 20–30 分钟、西综 40–60 分钟，剩余时间用于阅读或复盘；按当天情况灵活调整。

每天 1–2 小时完成全部科目的时间可能偏紧，以上日期是可调整的计划节点，不是保证完成的承诺。每月核对章节、阅读和实际时间；完整套卷可另找较长时段。旧记录继续保留，计划起点之前没有记录的日期不会被当作欠打卡。考试与报名时间仍以正式公告为准。

## 2026-09-13 可靠性更新

- 保存失败持续告警；读取异常时保留原始存档、阻止覆盖。
- 支持 JSON 文件选择、导入预览、按时间合并或完整恢复；主数据与导入前恢复副本一次写入，失败保持原状。
- 日历导出不再冒充备份；备份时间需用户确认文件已保存后记录，提醒周期可选 7/14/30 天。
- 科目时长可增减、直接修改，总时长自动求和；旧版未分类时长归入「其他」。旧版科目合计高于总时长时保留科目记录，不静默丢弃。
- 返回前台时自动跟随新的一天；主动查看历史时不跳转；未来日期只读。
- 停用固定任务保留过去记录；模考删除须确认。
- 首页优先展示任务，阶段与安装说明折叠；支持缩放、键盘勾选、深色模式和减少动画。
- 离线应用资源按版本整组安装，旧版本不会单独获取新 HTML；新版本就绪后提示用户保存并更新。
- 报名等日期明确为待核实的规划参考；200 分线不再自动决定志愿档位。

## 开发与测试

无 npm 运行时依赖、无构建步骤。需要 Node.js 22+ 运行测试，Python 3 可用于本地预览。

```sh
node --test tests/*.test.cjs
node --experimental-test-coverage --test --test-coverage-include=core.js tests/core.test.cjs
python3 -m http.server 8766 --bind 127.0.0.1
```

测试涵盖旧数据迁移、保存失败、损坏保护、原子恢复、未来日期、科目时长、备份提醒和 Service Worker 的版本一致性。覆盖率命令仅统计独立的数据核心，不代表整个 UI 的覆盖率。

浏览器验收：窄屏打卡 → 调整科目时长 → 输入复盘 → 刷新保留；备份预览与恢复；六个页面；离线重新打开；更新提示；无水平溢出。

### 文件

- `index.html`：页面壳、样式、状态与事件。
- `views.js`：六个页面、时长与备份交互。
- `core.js`：可独立测试的校验、旧数据兼容与纯计算。
- `sw.js`：版本固定的离线应用壳。
- `server.py`：原有可选本地同步服务；不是 GitHub Pages 后端。没有鉴权，不要暴露到公网。

### 发布约定

修改任一应用资源时，**同时递增 `sw.js` 的缓存版本**，并更新预缓存清单。必须把 HTML、脚本、manifest、图标一起提交，不能只替换 HTML。安装失败时继续保留旧版本；用户确认更新后才切换。

不要提交 `state.json`、个人 JSON 备份或真实学习记录。测试只使用合成数据。
